# 函数实验室 · Function Lab

一个开箱即用的函数绘图工具，面向大学微积分里的**含参函数求极限**与**一键求导**场景。

打开即用：<https://ayachikoko.github.io/function-lab/>

## 功能

- **函数绘图**：Canvas 2D 手写渲染，支持多函数叠加、颜色切换、显示/隐藏。
- **亮色界面**：浅色画布与纸张质感面板，长时间看公式更舒服。
- **单向缩放**：底部滚轮只缩放 X 轴，左侧滚轮只缩放 Y 轴；空白处滚轮双向缩放。工具栏也有 `X ±`、`Y ±`、`XY ±` 按钮。
- **拖动平移 / 双指缩放**：鼠标拖动画布平移；触屏支持双指捏合。
- **Geogebra 风格输入**：`2x`、`sin x`、`x sin(x)`、`|x|`、`2(x+1)`、`e^x`、`pi` 都能直接识别。
- **参数滑块**：表达式里出现 `x` 以外的字母（如 `a`、`b`）自动生成滑块；在参数行上滚动滚轮可微调（`Shift` ×10、`Alt` ×0.1），图像实时变化。
- **一键求导**：对当前选中的函数符号求导，结果像文件夹子项一样缩进挂在原函数下面；父函数改动时导函数会自动重算，遇到不可符号求导的函数自动切换为数值导数（虚线）。
- **数值求极限**：支持双侧 / 左 / 右 / `+∞` / `−∞`，使用 64 位高精度采样，能处理 `0/0`、`∞/∞`、振荡发散、左右极限不等。
- **照片识别**：拖入 / 选择 / 拍照 / 粘贴公式截图，本地 OCR（Tesseract.js）识别后可手动修正再导入。
- **点、切线与渐近线**：在曲线上左键单击，弹出点菜单，可显示该点坐标、画切线（方程同步标注在左侧函数框里）、自动检测并画出竖直 / 水平 / 斜渐近线。
- **分享链接**：函数、参数和视图会编码进 URL，复制即分享。
- **导出 PNG / 全屏**。

## 快捷键与小技巧

| 操作 | 效果 |
| --- | --- |
| 底部 30px 内滚轮 | 仅缩放 X 轴 |
| 左侧 30px 内滚轮 | 仅缩放 Y 轴 |
| 画布中间滚轮 | 双向缩放 |
| `Shift` + 滚轮 | 仅缩放 X 轴 |
| `Alt` + 滚轮 | 仅缩放 Y 轴 |
| 拖动 | 平移 |
| 双指捏合 | 双向缩放 |
| 左键单击曲线 | 显示点、切线、渐近线选项 |

## 本地运行

纯静态站点，无需构建：

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 技术说明

- [math.js](https://mathjs.org/)：表达式解析、符号求导、高精度 BigNumber 求值。
- [Tesseract.js](https://tesseract.projectnaptha.com/)：本地 OCR，语言包与核心文件全部随仓库分发，不依赖外部 CDN。
- 极限为**数值估算**：在趋近点两侧按 `1e-3 … 1e-15` 采样并判断收敛，适合快速判断与教学演示，不等同于符号证明。
- 渐近线同样为**数值检测**：竖直渐近线在当前视图内扫描，水平 / 斜渐近线在 `x→±∞` 取样判断；个别病态函数可能需要放大视图后再看。
- OCR 对印刷体效果较好，手写公式可能需要手动修正括号和上标。
